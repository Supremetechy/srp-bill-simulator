# SRP Electric Bill Calculator

A comprehensive tool for SRP customers to calculate and optimize their electric bills.

## Features

- Real-time bill estimation based on appliances and usage
- Historical bill analysis
- Personalized savings strategies
- Upload past bills for analysis
- Seasonal rate calculations

## Development

\`\`\`bash
npm install
npm run dev
\`\`\`

## Build

\`\`\`bash
npm run build
\`\`\`

## Deploy

\`\`\`bash
vercel --prod
\`\`\`
